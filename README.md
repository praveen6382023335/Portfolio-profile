## 📸 Hero Profile Photo

The uploaded photo has been placed in:
`assets/praveen-photo.jpg`

If you ever wish to swap it with a new photo:
1. Replace `assets/praveen-photo.jpg` with your new image file.
2. In `index.html` (line 96), verify the `src` attribute matches the file name:
   ```html
   <img src="assets/praveen-photo.jpg" alt="S. Praveenkumar" class="avatar-img" id="heroAvatar">
   ```

## 💻 How to Run Locally

You can simply double-click `index.html` to view it in any web browser, or run a local server:

```bash
# Using Python
py -m http.server 3000
```
Then open `http://localhost:3000` in your browser.
